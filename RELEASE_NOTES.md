SmartProctor v1.1.0
Native exam lockdown and mobile proctoring release.

Features
• Native Android screen pinning and screen keep-awake (ExamLock)
• Screenshot, recording, and task-switcher blocking via FLAG_SECURE
• Pre-exam Do Not Disturb (DND) silence checks and verification gates
• Real-time screen pin-exit detection with blocking interruption sheet and input locking
• New violation detection: PIN_EXITED, APP_BACKGROUNDED, FOCUS_LOST, and MULTI_WINDOW
• System back button interception with user alert toasts during exams
• Universal lockdown cleanup across all exit paths (submission, proctor stop, time-up, logout)
• Desktop web redirection for teachers and admins pointing directly to production dashboard
• Built-in in-app updates with automated versioning

Requirements
• Android 7.0 (Nougat) or higher for native mobile app
• Do Not Disturb permissions for interruption silencing
• Camera and microphone permissions
• Active internet connection
